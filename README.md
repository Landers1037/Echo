# Echo

个人本机使用的 Markdown 笔记 WebApp。React + TypeScript 提供编辑和预览，Go 管理普通 Markdown 文件、图片、分类、任务与提醒。发布时，前端嵌入 Go 可执行文件，运行成品不需要 Node.js。

## 开发启动

需要 **Node.js 22 或更新版本**、**Go 1.25 或更新版本**。在项目根目录运行：

```powershell
npm install
npm run dev
```

打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)。这一条命令同时启动 Vite 和 Go 后端，Go 默认监听 `127.0.0.1:8080`；前端通过同源代理访问 `/api`。前端热更新，修改 Go 源码后自动编译并重启后端；Go 编译失败时保留上一次成功运行的后端。按 `Ctrl+C` 停止两个进程。

开发时可使用环境变量指定笔记库：

```powershell
$env:ECHO_DATA_DIR = 'D:\MyNotes'
npm run dev
```

默认笔记库为项目根目录下的 `notes`，首次打开空库时创建欢迎笔记。应用默认仅供本机访问，不包含用户登录、远程同步或多人协作。

## 编译与运行

```powershell
npm run build
.\dist\echo.exe
```

构建依次执行 TypeScript 检查、Vite 打包和 Go 编译。Windows 输出 `dist/echo.exe`，其他系统输出 `dist/echo`。前端静态资源通过 `go:embed` 编译进入二进制；把该可执行文件复制到其他目录即可运行，实际笔记和图片写在外部数据目录。

运行参数：

```powershell
.\dist\echo.exe --data-dir 'D:\MyNotes' --addr 127.0.0.1:8080
```

打开 [http://127.0.0.1:8080](http://127.0.0.1:8080)。`--data-dir` 默认是**进程启动目录**下的 `notes`，不是可执行文件所在目录。`--addr` 默认 `127.0.0.1:8080`。`--dev` 仅用于开发时允许本机 Vite 来源，正常运行成品无需设置。

## 编辑、分类和外观

- 左侧按真实目录或独立逻辑分组浏览笔记，支持搜索、标签筛选、创建、移动、重命名、删除和回收站恢复。
- 右侧使用小尺寸「源码 / 预览」Tab，不使用编辑/预览双栏。CodeMirror 提供查找替换、撤销重做、折叠、自动补全和快捷工具栏。
- Markdown 预览支持标题、引用、列表、GFM 表格、勾选任务、图片与代码块；代码高亮和源码/预览行号分别可配置。
- 约 800ms 自动保存，也可以按 `Ctrl+S`。界面显示保存状态；保存失败保留本地草稿。外部编辑或其他标签页产生冲突时，不直接覆盖磁盘内容，可比较后保留草稿副本或明确覆盖。
- 支持明亮、暗黑、跟随系统、自定义强调色和动画开关。动画关闭同时作用于界面过渡与 Motion，系统减少动态效果设置也会生效。

每篇笔记可以设置多个标签和一个逻辑分组，分组不会移动 Markdown 文件；未设置分组的笔记归入“未分组”。删除分组会解除关联，删除标签会从关联笔记移除该标签，不删除笔记正文。

分类信息保存在 Markdown 开头的 YAML frontmatter：

```markdown
---
title: 其他工具使用的字段会保留
echo:
  tags:
    - 工作
    - 灵感
  group: 项目记录
---

# 笔记正文
```

文件没有 frontmatter 时，按空标签和未分组处理。已有 frontmatter 中的其他字段会保留；非法 YAML 会提示修复，分类修改不会静默覆盖非法内容。正文预览隐藏 frontmatter。

## 图片和资源目录

支持文件选择、拖放和剪贴板粘贴上传 PNG、JPEG、GIF、WebP 图片，默认单张不超过 20MB。上传后在编辑器原插入位置写入相对图片引用；失败时可以重试。

默认资源目录是笔记库中的 `.assets`，可以在设置中改为库内其他相对目录。更改时迁移资源并修改笔记中的引用；移动笔记时也会修正相关内部链接。资源目录必须位于笔记库范围内。

## 任务、看板与提醒

笔记中的 Markdown 勾选列表是任务来源；代码块中的示例任务不会进入任务列表。全局看板有“待办 / 进行中 / 已完成”三列，拖动或修改状态会同步回原 Markdown；可以从卡片定位来源笔记。

任务排期信息保存在任务行的隐藏注释中，例如：

```markdown
- [ ] 整理周报 <!-- echo-task: {"id":"stable-task-id","status":"todo","due":"2026-10-23T18:00:00+08:00","repeat":"weekly","timezone":"Asia/Shanghai"} -->
```

界面支持单次、每日、每周、每月重复，以及到期时间和提醒时间。默认使用创建任务时的本机时区；月度目标日期不存在时取当月最后一天。重复任务完成后记录历史，再推进到下一次未来周期；未完成时保持逾期，不不断生成任务副本。

网页打开时提供应用内提醒；用户主动允许浏览器通知后，可同时显示浏览器通知。网页关闭或后端停止期间不会执行独立的系统后台通知，到期项目会在重新打开后汇总提醒。应用持久化提醒确认状态，避免刷新和多标签页重复弹出同一周期提醒。

## 导出

可以导出当前笔记、多选笔记、整个分组或标签筛选结果。导出前先保存相关编辑，冲突或保存失败时停止导出。

| 格式 | 单篇 | 批量 |
| --- | --- | --- |
| Markdown | 原始 `.md`，或带图片的 ZIP | ZIP，保留目录结构并携带本地图片 |
| HTML | 独立 `.html` 文件 | ZIP，包含索引页及每篇笔记的 HTML |
| PDF | 专用打印页，通过浏览器另存为 PDF | 合并打印文档，每篇笔记另起一页 |

- **MD** 保留 frontmatter 和任务注释。直接下载 `.md` 不携带图片；ZIP 把图片放在包内 `.assets` 并修改导出副本的引用。
- **HTML** 内嵌样式、本地图片和已渲染代码高亮，不需要运行应用即可阅读；显示标题、标签和分组，任务呈现为静态状态。批量导出修正所选笔记之间的链接。
- **PDF** 点击后打开打印排版，使用浏览器“另存为 PDF”。默认 A4、浅色背景，隐藏应用控件；长代码换行、表格重复表头、图片等比缩放。具体纸张和边距也可在浏览器打印面板调整。
- 本地图片缺失时列出问题，可明确选择继续。远程图片保留外链，不自动下载；离线查看时可能无法显示远程图片。

## 数据、备份与恢复

```text
notes/
  欢迎使用 Echo.md
  子目录/
    笔记.md
  .assets/       # 图片，名称可在设置中修改
  .echo/         # 配置、提醒记录、回收站与恢复日志
```

备份时复制**整个笔记库目录**，包括隐藏的 `.echo` 和当前资源目录。建议停止后端后复制，以获得一致的文件快照。恢复时把完整目录复制到目标位置，再通过 `--data-dir` 指向它。应用删除的笔记或文件夹可在回收站中恢复。

Markdown 文件可以在其他编辑器中直接打开和修改。后端会重新检测文件变化；当前笔记如存在未保存内容，会先保留草稿并提示冲突。原始 HTML 不在预览中执行，文件访问限定在笔记库范围。

## 检查

```powershell
npm run typecheck
npm test
npm run build
```

`npm test` 执行 Go 单元/API 测试和前端 Vitest 测试。浏览器验收包括编辑/预览、分类筛选、图片粘贴、冲突、任务看板、提醒去重、导出、主题和窄屏布局；成品运行检查使用构建后的二进制，关闭前端开发服务器后访问生产地址。

## API 概览

所有接口位于 `/api`，使用 JSON（图片上传为 multipart、文件下载及 SSE 除外）。笔记写入和任务修改携带 `revision`；版本冲突返回 HTTP 409。

| 接口 | 用途 |
| --- | --- |
| `/tree`、`/notes`、`/folders` | 文件目录、笔记读写、移动、批量分类 |
| `/trash`、`/trash/restore` | 回收站和恢复 |
| `/groups`、`/tags` | 独立分组和标签管理 |
| `/assets`、`/settings` | 图片上传读取、配置和资源迁移 |
| `/tasks`、`/reminders`、`/reminders/ack` | 任务排期、提醒查询与确认 |
| `/events` | SSE 文件变更和提醒事件 |
| `/exports` | Markdown 下载、资源 ZIP 和一致性导出快照 |
